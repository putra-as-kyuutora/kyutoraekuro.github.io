Enigma Machine Simulator

Java Swing GUI Cryptography

🎯 Problem

Memahami dan mengimplementasikan metode enkripsi historis yang kompleks dari mesin Enigma era WWII membutuhkan pemahaman mendalam tentang algoritma dan state management.

💡 Solution

Membangun simulasi lengkap mesin Enigma menggunakan prinsip Object-Oriented Programming (OOP) di Java, dengan implementasi rotor mechanism dan plugboard yang autentik.

📚 Learning Outcomes

  • Complex Algorithm Implementation: Memahami dan mengimplementasikan algoritma enkripsi yang sophisticated
  • State Management: Mengelola multiple states (rotor positions, plugboard settings)
  • Historical Computing: Menghidupkan kembali teknologi komputasi klasik
  • OOP Mastery: Penerapan inheritance, encapsulation, dan polymorphism

🔧 Key Features

  • Authentic rotor mechanism simulation
  • Configurable plugboard settings
  • Real-time encryption/decryption
  • Interactive GUI with Swing
